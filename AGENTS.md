# Agent Guidelines for TECH6-H26

- This file contains project-specific instructions for AI agents working in this repository.

## Python Environment

- The Python code in this repository is intended to be run with the `TECH6` conda environment, which is already present on the system.
- Conda manages this environment: do not install any additional packages into it, and do not use `pip` to install packages.
- The targeted Python version is `3.14`.

## Code Style & Formatting

- **Quote style**: Use single quotes (`'...'`) for strings.
- **Docstrings**: Use NumPy style docstrings.
- **Formatting & Linting**: Use `ruff` for code formatting and linting. Ruff is installed in the `TECH6` conda environment.
